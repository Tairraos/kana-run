> 调研来源（2026-09 检索）：Tofugu《Learn Hiragana》与其 Kana Quiz（助记符先行、可选子集训练）；
> ResearchGate《Spaced repetition learning games on mobile devices》（SRS 游戏化）；

## 一、设计原则（来自调研的五条硬结论）

1. **助记先行，操练随后** —— 每个假名配一条中文助记（字形/字源双通道），先看后练。
2. **自适应重复本身就是奖励** —— SRS 薄弱假名更常出现；做错的题会"追着你来"。
3. **每日小循环** —— 每日目标 + 连击日历 + 御神签，把"打开一次"变成仪式。
4. **元成长层** —— XP/等级/称号/主题解锁/成就印章（判子）/言灵收集，外在奖励叠在内在成就感之上。
5. **题型多样防疲劳** —— 选择、反向选择、听音辨字、平片互认、配对消除、限时速答六种玩法。

## 二、玩法结构

| 模式 | 内容 | 通关/评分 |
| --- | --- | --- |
| 冒险闯关 | 24 关 × 4 篇（平假名篇 / 片假名篇 / 浊音篇 / 拗音篇），关卡=行；学习卡 → 8~10 题 | 0~3 星：满分 3★，≥85% 2★，≥60% 1★，未达不通过；篇内 ≥70% 关卡通过解锁下一篇（设置内可开"自由解锁"） |
| 极速挑战 | 60 秒限时四选一，速度递增，连击倍率 | 本地最高分 |
| 配对消除 | 假名 ↔ 罗马音记忆翻牌，6→8 对渐进 | 步数 + 用时评级 |
| 五十音图鉴 | 全表浏览 + 单假名详情（助记/字源/朗读/掌握度） | 点击任意假名随时复习 |

题型（闯关内混合）：看假名选拼音 / 看拼音选假名 / 听音辨字（有 ja 语音时启用）/ 平片互认。
复习混入：每关 30% 题目来自已学假名中 SRS 到期或薄弱项（自适应重复）。

## 三、记忆模型（SRS）

- 每假名一条记录 `{box, due, ok, ng}`，Leitner 盒 0~5，间隔 0 / 10min / 4h / 1d / 3d / 7d。
- 答对 box+1，答错 box=max(0,box-1) 且 2 分钟后重见。
- 掌握度星（图鉴展示）：box≥5 → 3★；≥4 → 2★；≥2 → 1★；其余未点亮。
- 出题权重：新字 ×3、薄弱 ×2、到期 ×1.5、连错 ×1.3（乘法叠加后加权抽样）。

## 四、奖励与经济

- **XP/等级**：答对 +10，连击每 5 连额外 +5；星级每颗 +30。等级解锁称号与主题。
- **花瓣（樱花钱）**：答对 +1 等；用于"言灵祈愿"扭蛋（20 花瓣/抽，权重 60/30/10，重复返还 6）。
- **御神签（每日一次）**：摇签 → 大吉…凶 + 当日增益（如 2× XP 持续至次日）。
- **成就 = 判子印章**：16 枚（完美主义、连击大师、夜行侠、七日不辍、平假名大师……），达成时红印砸屏 + 纸屑。
- **连击反馈**：连击数、日语称赞词（すごい！/ 素晴らしい！/ 完璧！）、音高随连击上升、烟花于里程碑绽放。
- **主题解锁**：夜樱（默认）/ 曙樱 Lv3 / 抹茶 Lv5 / 墨 Lv7。
- **每日目标**：完成 1 回合 + 答对 20 题，完成点亮当日日历、延续连击火焰。

## 五、视觉与声音

- 基调：**夜樱 × 霓虹** —— 深靛夜空 + 樱粉/青霓虹 + 朱红日之丸；富士山与鸟居剪影视差；花瓣常驻飘落。
- 字体：Yuji Syuku（笔触假名展示）+ Zen Maru Gothic（UI）+ Noto Sans SC（中文正文），在线加载、离线退化系统字体。
- 特效：canvas 樱花/烟花/纸屑/星光；答对星光迸溅、升级烟花大会、判子 stamp 音画。
- 声音：WebAudio 全程合成（正确和弦音高随连击上升、错误低鸣、翻牌、判子闷响、烟花爆裂、升段号角）；可选五声音阶环境 BGM；ja-JP 语音朗读假名（可用时）。
- 彩蛋：连点日之丸三下 → 樱花暴风雪。

## 六、技术定案

- 纯 vanilla HTML/CSS/JS；经典 `<script>` 顺序加载（file:// 可直接双击游玩）；localStorage 持久化（`kq_save_v1`）。
- 模块即命名空间：`U / KANA / ROWS / ACHV / KOTODAMA / SRS / QUIZ / SFX / FX / STORE / UI`。
- `tools/validate.js` 守护数据与逻辑不变量；浏览器自动化逐屏实测为发布门。
- 无障碍与性能：reduced-motion 降级、粒子数上限、移动端触控目标 ≥44px、键盘 1-4 作答。
