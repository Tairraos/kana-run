# 五十音物語 · KANA MONOGATARI

> 在夜樱之下，把五十音刻进记忆。
> 一个**纯网页、零依赖、可离线**的日语五十音学习游戏。双击 `index.html` 即可开始。

![home](dev-preview.png)

## 它怎么帮你记住

- **助记先行**：每个假名一条中文联想（如 ね＝猫尾巴卷成圈——ねこ），先看后练。
- **间隔复习（SRS）**：Leitner 五盒调度，答对隔更久再见、答错很快重逢；做错的假名会更频繁地出现。
- **混合出题**：关卡题 30% 来自你学过且快到期的假名，越学越科学。
- **多样题型**：看假名选拼音、看拼音选假名、听音辨字（需系统日语语音）、平片互认。
- **即时反馈**：答错立即展示正确答案与助记；连击有日语称赞词、音高攀升与烟花。

## 运行

- **直接玩**：双击 `index.html`（推荐 Chrome / Safari / Edge 现代浏览器）。
- **本地服务**（可选）：`python3 -m http.server 8377` 后访问 `http://127.0.0.1:8377/`。
- 进度自动保存在浏览器 localStorage，随时可玩、关页不丢。
- 在线时加载日文手写字体（Yuji Syuku 等）；离线自动退化为系统字体，功能不受影响。

## 关于进度与读音

- **读音**：学习卡与答题页点 🔊 即可朗读，同时弹出读音气泡；即使设备没有日语语音，读音（罗马音）也始终可见。若朗读无声，到「设置 → 声音」确认「假名朗读」已打开。
- **进度**：浏览器的「双击文件打开」与「本地服务打开」是**两个独立存档位**。换一种方式打开若发现进度不同，到「设置 → 存档」用**存档码导出/导入**搬运即可。隐私窗口可能无法保存进度，游戏会明确提示。
